# DIV Giveaway

A professional giveaway registration website for upcoming DIV apps.

## Important
This repository contains the public registration frontend. Participant information must be stored in a secure backend (such as Supabase/Firebase) rather than committed to GitHub. The admin dashboard should use authenticated access and server-side authorization.

## Features planned
- Giveaway landing page
- Participant registration
- Name, email, phone, country, app interest and optional social handle
- Admin-only participant dashboard
- Search and filtering
- Winner/selected status
- Gift-card delivery status and code recording
- Responsive mobile-first design
